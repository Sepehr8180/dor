# هم‌کلمه | بازی گروهی آفلاین اندروید

نسخه شخصی بازی کلمه‌ای با رابط فارسی راست‌به‌چپ، طراحی مینیمال و رنگ‌های پرکنتراست. نام «هم‌کلمه» فعلاً نام موقت پروژه است.

## امکانات نسخه اولیه

- بازی با ۴، ۶، ۸ یا ۱۰ نفر؛ هر دو بازیکن در یک تیم قرار می‌گیرند.
- ویرایش نام تیم‌ها و بازیکنان.
- انتخاب ۳، ۵ یا ۷ دور و زمان ۱ یا ۲ دقیقه برای هر نوبت.
- انتخاب دسته‌بندی‌ها و سطح سختی کلمات.
- تایمر، مکث و ادامه، پاسخ درست، رد کردن کلمه و پایان دستی نوبت.
- محاسبه امتیاز، چرخش خودکار نوبت تیم‌ها و صفحه نتیجه.
- ۱۷ دسته‌بندی پایه و ۱۰٬۱۸۱ کلمه در بانک اولیه.
- افزودن کلمه به دسته‌های موجود، ساخت دسته اختصاصی و حذف کلمات اختصاصی.
- ذخیره محلی کلمات و دسته‌های اختصاصی؛ برنامه مجوز اینترنت ندارد.

## بانک کلمات

فایل `app/src/main/assets/word_bank.json` شامل ۱۷ دسته و ۱۰٬۱۸۱ کلمه است: ۹٬۹۱۵ کلمه یکتا از ۹٬۹۶۵ رکورد بانک محلی APK ارسالی (پس از حذف ۵۰ مورد تکراری) و ۲۶۶ واژه تکمیلی که برای این نسخه اضافه شده‌اند. سطح سختی هر کلمه در سه سطح آسان، متوسط و سخت نگهداری می‌شود.

## ساخت APK

پروژه با Android Gradle Plugin 8.7.3، Kotlin 2.0.21 و Jetpack Compose آماده شده است. حداقل نسخه هدف Android 7.0 (API 24) است.

**با Android Studio:**

1. پوشه پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync انجام شود.
3. از مسیر `Build > Build Bundle(s) / APK(s) > Build APK(s)` خروجی Debug بسازید.

**با GitHub Actions:**

1. محتوای این پوشه را در یک مخزن GitHub قرار دهید.
2. از بخش `Actions`، گردش‌کار `Build HamKalame APK` را اجرا کنید.
3. خروجی `hamkalame-debug-apk` را از بخش Artifacts دریافت کنید.

این نسخه هیچ حساب کاربری، سرور، تبلیغات، فروشگاه یا قابلیت آنلاین ندارد. بانک اصلی داخل خود APK است و تغییرات شخصی در حافظه داخلی برنامه نگهداری می‌شوند.
